本テーマについて

学習目標:

  • HTML によって Web ページの構造を記述する基本的な方法がわかる
  • CSS によって Web ページの見た目を設定する基本的な方法がわかる
  • JavaScript によって Web ページのインタラクティブな処理を記述する基本的な方法がわかる
  • HTML, CSS, JavaScript の構文リファレンスから，構文の書式や使用方法の情報を入手できる．
  • HTML, CSS, JavaScript, 画像・音声・動画ファイルを組み合わせて簡単な Web ページが作成できる

プロジェクト課題について

実際のプロジェクト課題に取り組んだ場合どのような検索結果が表示されるのかをイメージして今日の講義で扱ったHTMLを使って表示結果のページを作成しました。
自分は番組表の検索結果を選び開始時間やタイトル、出演者などが書いてあるページを作成しました。
また見出し要素などを使ってどの部分に何が書かれているのかをまだ少ない知識を使ってなるべく見やすいようにしました。
番号なしのリストを使うことによってタイトルや番組説明といった各項目にそれぞれ何のことが書かれているのかをわかりやすいように段落を分けました。

各授業会の学習事項

第1回 WWW と HTML

今回の講義では実際に手を動かしHTMLを使ってWebページに文字を入力したりURLや画像などを貼り付けたりした。
さらには文字のフォントサイズ変更や番号ありなしのリスト作成の仕方、HTMLの特殊文字の存在についてや入力の仕方についても学んだ。

演習の成果:演習1-4: HTMLのさまざまな要素

第2回 CSS による Webページの装飾

今回の講義では主にCSSを扱いページの装飾についてを学びました。 htmlの部分にcssのファイルに従って装飾するように指示し、文字色を変更したりグラデーションを追加したりした。 さらにpaddingやmarginなどで隙間を開けたりしてページを見やすく工夫したりしました。

演習の成果:演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScriptの基本

今回の講義ではjavascriptについて扱い、javascriptの特徴や自分達がプログラミングで学んだjavaとの違いなどを学びました。

演習の成果:演習3-6:オブジェクトの参照

第4回 DOMとJavaScript

まずkazuate.htmlは、kazuate.jsを読み込むようになっている。その次のinput要素でテキストボックスを作成し、button要素でユーザがテキストボックスに入力した数値を回答するようになっている。 そしてkazuate.jsはまずMath.ramdomを使ってランダムな答えを生成してkotaeという変数に代入し、コンソールのログでそれを確認できるようにしている。 15〜17行目ではquerySelectorでhtmlファイルのspan要素の回数を変更して更新されるようにしている。 21〜40行目ではユーザがテキストボックスに入力した数字がkotaeと一致しているかを確かめて回答回数に応じて表示結果を変えるようにif文を使って判別している。 もし4回以上の回答をしていた場合には判別せずに答えと既にゲームが終わっていることを表示するようにしている。

第4回課題:kazuate.html

演習の成果:演習4-10:足し算ページ
